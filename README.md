# MemoryBar · Мониторинг Mac

Нативный монитор ресурсов macOS в строке меню. Версия **0.2.5**.

Память, процессор, сеть, диск и аккумулятор — в компактной панели со стеклянным оформлением. Нажмите на карточку или вкладку, чтобы выбрать показатель для строки меню. Выбор сохраняется между запусками; для памяти и ЦП отображаются значок и процент.

## Установщик 0.2.5

```sh
zsh scripts/build.command
zsh scripts/package.command
open dist/MemoryBar-0.2.5-macOS-arm64.pkg
```

Установщик помещает «Мониторинг Mac.app» с фирменным значком в `/Applications` («Программы»). Откройте приложение двойным щелчком или через Spotlight: «Мониторинг Mac». Панель открывается сразу; повторный запуск показывает панель уже работающего экземпляра. Приложение продолжает работать в строке меню. Скрипт упаковки не запускает установку и не меняет установленное приложение. Установщик без Developer ID и заверения Apple; macOS может потребовать разрешение владельца. Старую копию «Мониторинг RAM» при ручном обновлении следует закрыть штатно и перенести из «Программ», чтобы не путать версии. Установщик сам старые копии не удаляет.

## Возможности

- RAM, сжатая и проводная память, кеш и swap.
- Загрузка ЦП: пользователь, система, свободные ресурсы, число процессов.
- Скорость сети, трафик и пакеты физических интерфейсов `en*`.
- Чтение и запись диска, суммарные байты и операции.
- Заряд аккумулятора, время до зарядки/разрядки и история до 12 часов.
- Графики последних двух минут, обновление каждые две секунды.
- Панель без прокрутки, крупные области нажатия и матовая навигация.

## Сборка и запуск

Нужны Mac с **Apple Silicon**, Command Line Tools/Xcode с совместимым Swift и **SDK macOS 26 или новее**. Проверено: Swift 6.3.3, SDK 26.5, macOS 26.7.1. Скрипт предпочитает SDK 26.5, если он установлен, иначе использует выбранный SDK Xcode.

```sh
git clone https://github.com/zakras030997-byte/memorybar.git
cd memorybar
zsh scripts/build.command
open 'build/Мониторинг Mac.app'
```

Сборка создаёт приложение, подписывает его локальной подписью и запускает встроенную проверку расчётов. Существующий результат в `build` не перезаписывается. Установленное приложение скрипт не меняет.

Целевая версия **macOS 14+**; запуск на macOS 14/15 отдельно не проверялся. Стеклянное оформление доступно на macOS 26, на более ранних версиях предусмотрен системный полупрозрачный фон. Сборка Intel отдельно не настроена и не проверена.

Для постоянной установки перенесите приложение в свою папку «Программы». Для автозапуска добавьте его в «Системные настройки → Основные → Объекты входа». Публичная сборка содержит основное приложение; старый отдельный виджет рабочего стола в неё не входит.

## Проверка

```sh
'build/Мониторинг Mac.app/Contents/MacOS/MemoryBar' --self-test
'build/Мониторинг Mac.app/Contents/MacOS/MemoryBar' --probe
```

`--self-test` проверяет вычисление скоростей, пропуски данных, сброс счётчиков и оценки времени. `--probe` выводит два локальных снимка показателей с интервалом две секунды. `--show` открывает панель при запуске приложения.

## Данные и ограничения

Сбор показателей выполняется локально, без отправки данных и без прав администратора. Выбранная вкладка хранится в настройках приложения. История аккумулятора сохраняется в `~/Library/Application Support/ai.anodhas.MemoryBar/battery-history.json` и накапливается по мере работы приложения.

Счётчики сети исключают виртуальные туннели и мосты, чтобы не считать один трафик дважды. Дисковые показатели суммируют доступные macOS счётчики накопителей. Мощность батареи в ваттах не равна показателю «Энерговоздействие» и не отражает полное потребление Mac от розетки. Недоступные измерения показываются прочерком.

## Исходники

- `Sources/MemoryBar.swift` — интерфейс, история и расчёт показателей.
- `Sources/Metrics.m` — чтение системных счётчиков Mach, sysctl и IOKit.
- `Resources/` — описание приложения и значок.
- `scripts/build.command` — самостоятельная сборка без внешних зависимостей.
